Bob: An Agentic IDE

Architecture overview

  • Bob is an agentic IDE that consists of:
    1. An agentic harness

      A sophisticated orchestration component responsible for reasoning, planning, and execution. It manages memory across multi-step tasks, coordinates subagents for parallel or delegated work, and drives tool invocation — enabling Bob to act autonomously on complex, multi-turn goals.

    2. An LLM gateway

      A routing layer that directs requests to the most appropriate language model based on task type, latency, and capability fit — abstracting model selection away from the developer.

    3. Frontier LLMs

      State-of-the-art models from multiple vendors, each vetted and tested by IBM for quality, safety, and suitability for enterprise IBM i workloads.

Best Practices for Context Management

How to get better, more consistent output from Bob

1
Be specific in your prompt State the task, constraints, and expected format. Vague prompts produce vague answers.
2
Use the right mode & skills Activate IBM i Developer mode so Bob loads the correct domain instructions automatically.
3
Scope the context deliberately Reference only the files relevant to your task. Unrelated code adds noise and dilutes precision.
4
Iterate on the response Follow up with clarifying prompts. Treat the first response as a draft, not a final answer.
5
Provide examples where precision matters For code generation or transformations, include a before/after example in the prompt to anchor the output style.

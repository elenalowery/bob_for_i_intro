Part 1 — Exercise

Consistency of Output

Use a reusable template to generate consistent COBOL programs on IBM i

  1. 1

    In Bob, select the IBM i Developer mode.

  2. 2

    Generate a reusable COBOL boilerplate template.

    Prompt

    Please generate a boilerplate template for COBOL on IBM i programs. Make sure to include "Generated by Bob". Save it as COBOL_TEMPLATE.CBLLE

  3. 3

    Review the generated template. Make any changes you wish before proceeding.

  4. 4

    Generate a first program from the template — an employee data retrieval program.

    Prompt

    Generate a sample COBOL on IBM i program. Use @COBOL_TEMPLATE.CBLLE as the template. The program retrieves data from an employee table using SQL. This is a code sample — you can create sample fields for the employee table. Save the program as GET_EMPLOYEES.CBLLE

  5. 5

    Generate a second program from the same template — a products retrieval program.

    Prompt

    Generate a sample COBOL on IBM i program. Use @COBOL_TEMPLATE.CBLLE as the template. The program retrieves products from a products table using SQL. This is a code sample — you can create sample fields for the products table. Save the program as GET_PRODUCTS.CBLLE

  6. 6

    Start a new task and switch to Agent mode. Compare the two generated programs.

    a

    Prompt

    In terms of formatting and structure, are @SAMCO/QCBLLESRC/GET_EMPLOYEES.CBLLE and @SAMCO/QCBLLESRC/GET_PRODUCTS.CBLLE similar?

    ⓘ  Starting a new task clears the prior context — this tests whether consistency comes from the template itself, not from conversation history.

Getting Started

Recommendations for Getting Started

Build confidence gradually — start safe, stay deliberate, and share what you learn

1
Start with low-risk, high-value tasks

Begin with code understanding, documentation, and test generation. These tasks carry no risk of changing production systems, and they deliver immediate value — making them the ideal starting point for learning how to work with an agentic AI.

2
Ask Bob to explain itself before it acts

While learning, always verify that Bob understands the task and review its approach before execution. Use these prompts:

  • Do you support this task? What skills or tools will you use?
  • Share the plan for completing this task without executing it.
3
Work with copies of production code first

Pull source members into a development library or local workspace before involving Bob. Validate changes thoroughly in a test environment before promoting to production.

4
Get comfortable with rollbacks

Know how to undo changes before you make them. Use source control, journal receivers, or save objects so you have a clear path back if a result is not what you expected.

5
Do not enable auto-approval

The confirmation step before each tool invocation is your most important safety net. Keep it on. Review what Bob is about to do — especially for write, compile, and execute actions — before approving.

6
Think in processes, not one-off sessions

Invest time in creating reusable prompts, templates, and workflows. An interactive session with Bob is useful, but a well-defined repeatable process is far more valuable at scale. If you do work interactively, capture what worked: summarize completed steps and save them as a reusable prompt or workflow for next time.

7
Share your findings with the team

Agentic AI tools improve fastest through shared experience. Document what worked, what didn't, and any prompts or workflows you've built. Your team's collective knowledge is the fastest path to consistent, high-quality results.

🎯 The goal is not to move faster on day one — it's to build enough confidence and process discipline that you can move faster, safely, every day after that.

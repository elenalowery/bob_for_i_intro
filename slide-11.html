Working Connected and Disconnected to IBM i

Bob's capabilities differ depending on whether you have a live IBM i connection via Code for IBM i

Connected

Live IBM i session
  • ✓ Bob works directly with source on IBM i — reads and writes members in QSYS and IFS stream files in real time.
  • ✓ You can execute commands — CL, SQL, and PASE — as part of any task.
  • ✓ You can compile and test directly: trigger Code for i build actions and run RPGUnit test suites.
  • ✓ Permissions are tied to the IBM i user ID in the active Code for i connection — Bob can only do what that user is authorized to do.
  • ⚠ Important: Changes made directly on IBM i can be rolled back, but this depends on how you have configured journaling and how you interact with Bob. Review before applying changes in production.

Disconnected

No live IBM i session
  • ✓ Bob works with a local copy of code that you have manually pulled from IBM i into the workspace.
  • ✓ You can document, analyze, review, and generate code — all AI assistance is fully available.
  • ✓ Generated or updated code can be manually copied back to IBM i and compiled using your usual tools.
  • ✗ Commands cannot be executed — CL, SQL, PASE, compile, and test actions require a live connection.
Capability Connected Disconnected
Code generation & analysis ✓ Yes ✓ Yes
Read & write source members / IFS ✓ Yes △ Local copy only
Execute CL / SQL / PASE commands ✓ Yes ✗ No
Compile & run tests ✓ Yes ✗ No
IBM i documentation search (RAG) ✓ Yes ✓ Yes
